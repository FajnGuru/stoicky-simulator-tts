# Stoický Simulátor - AI TTS Edition

Interaktivní prezentace s českým audio předčítáním (Gemini 2.5 TTS).

## Použití

Otevřete `index.html` v prohlížeči. Podporuje:

- Gemini TTS hlasy (Zephyr, Puck, Kore, Aoede)
- Systémový hlas prohlížeče
- Vlastní audio soubory
- Automatické přehrávání
- Fullscreen režim

## Technologie

- Alpine.js
- Tailwind CSS
- Font Awesome
- Gemini 2.5 Flash Preview TTS

Vytvořeno pro trénink stoické mentality a svalu proti odmítnutí.

Repo: https://github.com/FajnGuru/stoicky-simulator-tts
