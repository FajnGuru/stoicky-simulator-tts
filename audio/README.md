# Předgenerované audio

Umístěte sem soubory ve formátu:
`slide-01-zephyr.wav`
`slide-01-puck.wav`
`slide-01-kore.wav`
`slide-01-aoede.wav`
...

Pokud soubor pro daný slide + hlas neexistuje, prezentace automaticky spadne na:
1. Custom audio (nahrané uživatelem)
2. Live Gemini TTS (pokud je API klíč)
3. Systémový hlas prohlížeče

Soubory můžete vygenerovat přes Gemini TTS API a uložit sem.
